# AFTERLIGHT — 月が残した街

ハート型の月、無機質なビル、まばらな窓明かり。人の気配だけが残る夜の街を、歩いて、走って、壁を登って探索する **Three.js 製の一人称ゲーム**です。

建物、車、看板、月、雨、環境音をコードで生成しています。既存ゲームのモデル・画像・音楽は使用していません。

## 起動

Node.js 20.x の 20.19 以上、または 22.12 以上を使用してください。

```sh
npm ci --cache ./.npm-cache
npm run dev -- --port 5174
```

ブラウザで <http://127.0.0.1:5174/> を開き、「開始」を押してください。キーボードとマウスのある PC 向けです。`index.html` の直接ダブルクリックでは動作しません。

`AFTERLIGHT.code-workspace` は、このフォルダだけを開くための VS Code / Cursor 用ワークスペースです。Codex ではこのリポジトリのフォルダをプロジェクトとして追加してください。

## 操作

| 操作 | キー |
| --- | --- |
| 移動 | W / A / S / D（矢印キーも可） |
| 見回す | マウス。マウス固定を利用できない環境ではドラッグ |
| ダッシュ | Shift 長押し |
| ジャンプ | Space |
| 空中ダッシュ | 空中で Q（移動入力方向へ、入力がなければ視線方向へ。着地まで1回） |
| 壁走り | 空中で壁に沿って Shift + W（約2秒） |
| 壁につかまる | 壁の方向を向き、W + Space で壁へジャンプ |
| 壁を登る・降りる | つかまった状態で W / S |
| 壁を速く登る | つかまった状態で Shift + W |
| 壁を左右に移動 | つかまった状態で A / D |
| 壁からジャンプ | つかまった状態で Space を押し直す |
| 壁から手を離す | E |
| 屋上に乗り越える | W で壁の上端まで登ると自動 |
| 地図の表示切替 | M |
| 操作説明 | H または右上の「?」 |
| 交差点に戻る | R |
| 一時停止 | Esc |

Space の押しっぱなしで壁蹴りを繰り返すことはありません。W を離すと壁につかまって静止します。屋上からも普通にジャンプできます。

壁につかまると体力を消費し、地面・屋上で回復します。なくなると手が離れます。落下ダメージはありません。街と屋上にある5つの光に触れると、収集した数が小さな点で一時表示されます。集め終わった後も探索できます。

## 街と移動の調整

- 探索範囲は約 516m × 528m。中央の大通り、左右の路地地区、外側の地区、北側の延長区画を探索できます。
- 405 棟の建物の間に、L字の路地、抜け道、短い行き止まり、28か所の中庭があります。通路は314区間で、うち80区間が幅3.8〜4.4mの細い裏路地です。
- 大通りのビル本体は33〜62m。路地のビルも1〜2階分高くし、階高と窓の寸法を維持しています。中央の劇場タワーは本体64m、先端約97mです。
- 大通りの車道は約20.8m幅、歩道は片側約5m幅。信号・街路小物を道路端へ揃え、店舗入口には扉枠・取っ手を付けています。
- 路地側のビルには上層階のセットバックと屋上テラスを、大通りには出窓・外階段・段状の屋上部分を追加しています。テラスや階段の足場には当たり判定があります。
- 6か所の渡り廊下の下を通り抜けられます。壁登りでその屋上にも移動できます。
- 通常移動は 9.5m/s、Shift ダッシュは 18m/s。視点の高さは 2.4m です。
- 視野角は縦68度です。屋上の光はビルの高さに追従して配置されます。
- 壁登りは 10m/s、Shift 併用で 15m/s。登る壁を固定し、カメラの向きに左右されず壁上を横移動できます。
- 屋上への乗り越えは約 0.3 秒。カメラの上下動を滑らかにし、頭の揺れと左右の傾きをなくしています。
- 空中ダッシュは約 0.19 秒の水平移動です。壁走り中にも Space で壁を蹴れます。

## 描画・音

- 操作説明は右上の「?」または H キー、ミニマップは M キーで開けます。
- 右上の設定から「高 / 軽量」、マウス感度、雨を変更できます。
- 高品質ではネオンの発光と路面への鏡面反射を描画します。
- 大通りの4交差点には横型の車両用信号と歩行者信号があります。車両用は44秒周期で青・黄・赤が切り替わり、歩行者用も連動します。交差点ごとに時間をずらしています。
- 横断歩道、縁石、道路標識、消火栓、パーキングメーター、配電盤、ガラスと時刻表のあるバス停を配置しています。
- 一部の看板が不規則に点滅し、故障した配線から短い電気のアークと火花が出ます。
- 路地には傷んだゴミ箱、ゴミ袋、へこんだ空き缶、紙くずを配置しています。
- ネオンの照り返しにはプレイヤーに近い4つのライトを再利用し、大きな街でも光源の数を抑えています。
- 軽量では反射と発光処理を省き、描画解像度を抑えます。
- 環境音は初期状態でオフです。スピーカーボタンで雨と街の低い響きをオンにできます。
- 描画設定のみブラウザに保存します。光の収集状態は再読み込みでリセットされます。
- WebGL 2 に対応したブラウザが必要です。表示にはシステムフォントを使用しています。

### 仕組み

**Three.js** は、ブラウザの GPU を使う WebGL を扱いやすくするライブラリです。建物や窓は同じ形状を大量に描くので、`InstancedMesh` で材質ごとにまとめ、描画命令を減らしています。ネオンには [UnrealBloomPass](https://threejs.org/docs/pages/UnrealBloomPass.html) を使用し、明るい箇所の周囲へ光をにじませています。

衝突判定は建物を直方体（AABB）として扱い、プレイヤーを高さと半径のある物体として計算します。物理は 1/120 秒ずつ進めるため、描画速度の違いで壁をすり抜けにくい構造です。壁登りは「ジャンプの意図」「壁との距離」「壁を向いていること」を確認して開始します。頂上では上へ移動してから屋上の内側へ進むので、壁の内部を通り抜けずに乗り越えます。

開発サーバーでは `?view=alley`、`?view=roof`、`?view=trash`、`?view=sparks` を付けて路地・屋上・小物・火花の確認用視点を開けます。`?view=corner`、`?view=passage`、`?view=facade` はL字路・渡り廊下・壁面の確認用です。`?view=traffic` と `?view=traffic-red` は車両信号が青・赤の時刻に固定し、火花の視点も放電中の時刻に固定します。これらの確認用機能は本番ビルドでは無効です。

これは探索用のプロトタイプです。街の外周には移動範囲の制限があり、戦闘・第三者視点・スマートフォン用操作はありません。

## 公開用ビルド

`npm run build` で生成する `dist/` を静的ホスティングに配置できます。`vite.config.js` の `base: './'` によりサブディレクトリにも配置可能です。GitHub へのソース公開だけでは、ゲームの Web 公開は行われません。
