# AFTERLIGHT — 月が残した街

ハート型の月、無機質なビル、まばらな窓明かり。人の気配だけが残る夜の街を、歩いて、走って、壁を登って探索する **Three.js 製の一人称ゲーム**です。

建物、車、看板、月、雨、環境音をコードで生成しています。既存ゲームのモデル・画像・音楽は使用していません。

## 起動

Node.js 20.19 以上、または 22.12 以上を使用してください。

```sh
npm ci --cache ./.npm-cache
npm run dev -- --port 5174
```

ブラウザで <http://127.0.0.1:5174/> を開き、「開始」を押してください。キーボードとマウスのある PC 向けです。`index.html` の直接ダブルクリックでは動作しません。

`AFTERLIGHT.code-workspace` は、このフォルダだけを開くための VS Code / Cursor 用ワークスペースです。Codex ではこのリポジトリのフォルダをプロジェクトとして追加してください。

## 操作

| 操作 | キー |
| --- | --- |
| 移動 | W / A / S / D（矢印キーも可） |
| 見回す | マウス。マウス固定を利用できない環境ではドラッグ |
| ダッシュ | Shift 長押し |
| ジャンプ | Space |
| 壁につかまる | 壁の方向を向き、W + Space で壁へジャンプ |
| 壁を登る・降りる | つかまった状態で W / S |
| 壁を左右に移動 | つかまった状態で A / D |
| 壁からジャンプ | つかまった状態で Space を押し直す |
| 壁から手を離す | E |
| 屋上に乗り越える | W で壁の上端まで登ると自動 |
| 地図の表示切替 | M |
| 操作説明 | H または右上の「?」 |
| 交差点に戻る | R |
| 一時停止 | Esc |

Space の押しっぱなしで壁蹴りを繰り返すことはありません。W を離すと壁につかまって静止します。屋上からも普通にジャンプできます。

壁につかまると 体力 を消費し、地面・屋上で回復します。なくなると手が離れます。落下ダメージはありません。街と屋上にある5つの光に触れると、収集した数が小さな点で一時表示されます。集め終わった後も探索できます。

## 描画・音

- 操作説明は右上の「?」または H キー、ミニマップは M キーで開けます。
- 右上の設定から「高 / 軽量」、マウス感度、雨を変更できます。
- 高品質ではネオンの発光と路面への鏡面反射を描画します。
- 軽量では反射と発光処理を省き、描画解像度を抑えます。
- 環境音は初期状態でオフです。スピーカーボタンで雨と街の低い響きをオンにできます。
- 描画設定のみブラウザに保存します。光の収集状態は再読み込みでリセットされます。
- WebGL 2 に対応したブラウザが必要です。表示にはシステムフォントを使用しています。

### 仕組み

**Three.js** は、ブラウザの GPU を使う WebGL を扱いやすくするライブラリです。建物や窓は同じ形状を大量に描くので、`InstancedMesh` で材質ごとにまとめ、描画命令を減らしています。ネオンには [UnrealBloomPass](https://threejs.org/docs/pages/UnrealBloomPass.html) を使用し、明るい箇所の周囲へ光をにじませています。

衝突判定は建物を直方体（AABB）として扱い、プレイヤーを高さと半径のある物体として計算します。物理は 1/120 秒ずつ進めるため、描画速度の違いで壁をすり抜けにくい構造です。壁登りは「ジャンプの意図」「壁との距離」「壁を向いていること」を確認して開始します。頂上では上へ移動してから屋上の内側へ進むので、壁の内部を通り抜けずに乗り越えます。

これは探索用のプロトタイプです。街の外周には移動範囲の制限があり、戦闘・第三者視点・スマートフォン用操作はありません。

## 公開用ビルド

`npm run build` で生成する `dist/` を静的ホスティングに配置できます。`vite.config.js` の `base: './'` によりサブディレクトリにも配置可能です。GitHub へのソース公開だけでは、ゲームの Web 公開は行われません。
